# GEO 1.3.1 完整使用手册

> 适用对象：第一次接触本软件的品牌运营、内容编辑、发布人员和内部验收人员  
> 适用范围：Windows 桌面 App 的手动流程与“一键 GEO”流程  
> 适用版本：`1.3.1` Windows 桌面版  
> 更新日期：2026-09-17

## 1. 先理解这套软件是做什么的

这套软件把 GEO 内容工作的主要步骤放在一个本机 App 里：

```text
建立品牌资料
  → 配置写稿/调优模型
  → 创建或导入文章
  → 人工编辑与 GEO 优化
  → 准备图片或视频
  → 平台预检
  → 创建并执行发布任务
  → 核验平台结果
  → 测量 AI 可见度并复盘成本
```

你可以选择两种工作方式：

| 工作方式 | 适合谁 | 特点 |
| --- | --- | --- |
| 手动流程 | 需要逐篇审稿、逐项确认的运营人员 | 每一步都由人打开页面、检查和确认，控制最细 |
| 一键 GEO | 已有稳定项目配置，希望串行批量处理的人 | 一次配置后自动写稿、优化、预检和按授权发布，异常会暂存后继续 |

新用户请先掌握手动流程。手动跑通一篇内容后，再使用一键 GEO。

软件可以提高内容生产、检查和分发效率，但不能保证搜索引擎收录、AI 抓取、AI 引用、平台审核或流量结果。

## 2. 第一次打开软件

### 2.1 启动和登录

1. 双击 `GEO-Content-Platform.exe`。
2. 第一次启动时，设置本机管理员口令。
3. 按页面要求再次输入口令并保存。
4. 以后启动软件时，使用这个口令登录。

口令只在本机使用，目前没有“忘记密码”自助找回。不要删除或手工修改本机 `auth.json`。

如果软件提示“已经运行”，先检查任务栏和已有窗口。相同数据目录只能运行一个实例。

### 2.2 先看构建类型

桌面包分为两类：

- `safe`：可建项目、写稿、优化、分析和预检，但不能真实发布。
- `authorized_real`：发布运行时检查通过后，才显示媒体账号和真实发布能力。

看不到“媒体账号”或“发布中心”，不一定是故障。先检查交付包 manifest 中的 `publishing_profile`。

### 2.3 建议先备份

登录后点击标题栏的“立即备份”。完整迁移或升级前，还应在退出软件后备份整个目录：

```text
%LOCALAPPDATA%\GEOContentPlatform
```

这个目录可能包含项目、文章、回答样本、媒体账号会话和其他敏感数据，不要上传到公共网盘或群聊。

## 3. 左侧菜单分别做什么

| 菜单 | 用途 |
| --- | --- |
| 首页 | 查看整体工作台和近期状态 |
| 媒体账号 | 登录、检测、重新连接或解绑平台账号；仅发布构建显示 |
| 品牌项目 | 保存品牌、产品、官网、关键词和竞品等基础资料 |
| 一键 GEO | 批量串行执行写稿、优化、预检和授权发布 |
| AI 内容创作 | 手动生成、编辑、评分并保存单篇或批量草稿 |
| 内容库 | 管理稿件、筛选状态、继续编辑、优化或进入发布 |
| GEO 优化 | 对保存的文章生成优化预览，人工比较后决定是否覆盖 |
| AI 可见度 | 导入/采样 AI 回答、做本地分析、站点审计和项目诊断 |
| 成本账单 | 查看真实模型调用、Token 和费用回执 |
| 素材管理 | 上传、预览、下载和删除图片或视频 |
| 发布中心 | 选择稿件、渠道、账号、素材，完成预检和发布核验 |
| 系统设置 | 配置写稿、调优、评估和生图模型 |
| 关于 | 查看版本和产品边界 |

## 4. 开始工作的正确顺序

第一次使用推荐按以下顺序：

1. 建品牌项目。
2. 配置写稿模型。
3. 先手动生成一篇文章。
4. 人工编辑并保存。
5. 手动执行一次 GEO 优化。
6. 在内容库标记为“就绪”。
7. 准备媒体账号和素材。
8. 在发布中心预检。
9. 先用 Demo；确认无误后再真实发布。
10. 发布后核验结果，并用 AI 可见度做同口径复测。

下面逐步说明。

## 5. 第一步：建立品牌项目

打开“品牌项目”，点击“新建品牌项目”。

### 5.1 字段怎么填写

| 字段 | 填写建议 | 示例 |
| --- | --- | --- |
| 品牌名称 | 使用正式、固定的品牌主名 | XX科技 |
| 所属行业 | 写客户能理解的行业名称 | 企业人工智能 |
| 产品名称 | 填主要产品或服务名 | 企业 AI Agent 平台 |
| 官方网站 | 填公开 HTTPS 官网 | `https://example.com` |
| 品牌介绍 | 写服务对象、核心能力和已经确认的事实 | 为中小企业提供 AI Agent 部署与管理工具 |
| 核心关键词 | 输入一个后按 Enter，再继续添加 | AI Agent、企业自动化 |
| 竞争品牌 | 输入一个后按 Enter，可添加多个 | 竞品 A、竞品 B |

### 5.2 品牌资料怎么写才安全

- 只写已经确认的产品事实。
- 不要编造客户案例、融资、认证、销量或效果数据。
- 官网应与品牌真实对应。
- 品牌名不要过短或含糊，否则 AI 可见度分析容易误判。
- 关键词要围绕真实业务，不要堆入大量不相关热词。

点击保存后，项目会出现在项目列表。以后可以点击“编辑底稿”修改，也可以从项目卡片直接进入“一键 GEO”。

## 6. 第二步：配置 AI 模型

打开“系统设置”。当前有四个模型角色：

| 角色 | 用途 | 是否必须 |
| --- | --- | --- |
| 写稿模型 `WRITE` | 单篇/批量生成文章 | 内容创作必须 |
| 调优模型 `REVIEW` | GEO 优化和内容复核 | 可独立配置，也可按界面规则回退 |
| 评估/回测模型 `EVAL` | 独立评估和 API 可见度采样 | 做回测时使用 |
| 生图模型 `IMAGE` | 生成文章封面 | 可选 |

### 6.1 配置写稿模型

1. 选择“写稿模型”。
2. 选择千问、DeepSeek、豆包或自定义兼容服务。
3. 填写 `Base URL`。
4. 填写精确模型名称。
5. 填写 API Key。
6. 点击保存。
7. 点击“测试已保存角色”。

测试成功后会显示服务商、模型、耗时和实际请求地址。测试本身是一次真实模型调用，会进入成本账单。

### 6.2 配置调优和评估模型

1. 切换到“调优模型”或“评估/回测模型”。
2. 如果使用同一服务地址，可以勾选“复用写稿模型密钥”。
3. 填写模型名称并保存。
4. 执行连接测试。

如果调优模型和写稿模型完全相同，页面可能提示它不是独立模型。需要多模型复核时，应使用不同模型 ID、服务商或服务地址。

### 6.3 配置生图模型

IMAGE 角色只接受兼容 `/images/generations` 的图片模型。不要把视频模型配置到这里。测试 IMAGE 会实际生成并丢弃一张合成测试图，也会产生费用回执。

### 6.4 模型配置常见错误

- Base URL 必须是受支持的公开 HTTPS 地址。
- 模型名必须与供应商实际模型 ID 一致。
- API Key 无效会在测试时失败。
- “连接成功”只证明接口可访问，不代表长文章一定能在时限内完成。
- 不要连续点击测试或生成；结果未知时先看成本账单。

## 7. 手动流程一：创作一篇文章

打开“AI 内容创作”。

### 7.1 填写生成要求

1. 选择品牌项目。
2. 可选一个内容模板；没有需要时选“不使用模板”。
3. 填写文章主题。
4. 选择或输入目标关键词。
5. 选择目标字数：200、600、1000、1500 字，或自定义 200–3000 字。
6. 选择内容类型。
7. 选择目标平台；没有明确平台时选通用内容。

内容类型包括：行业科普、品牌介绍、产品介绍、解决方案、对比文章、FAQ 和新闻稿。

目标平台只是写作方向。真正发布时，发布中心还会根据每个平台的限制生成独立短版。

### 7.2 使用内容模板

点击内容模板右侧的管理按钮，可以：

- 使用内置模板；
- 复制内置模板；
- 新建自定义模板；
- 编辑或删除自己的模板。

模板指令应说明结构、语气和事实边界。不要在模板里要求模型编造数据或伪造来源。

### 7.3 建立 AI 引用蓝图

填写项目和主题后，点击“建立蓝图”。蓝图会在本机整理：

- 用户可能提出的问题；
- 搜索/决策意图；
- 品牌实体和关键词；
- 证据边界；
- 发布前阻断和提醒。

你可以点击蓝图中的问题，把它直接设为文章主题。修改项目、主题、关键词、字数或内容类型后，如果页面提示“参数已变更”，应点击“刷新蓝图”。

蓝图不调用外部模型，但也不代表文章已经被 AI 收录。

### 7.4 生成草稿

1. 再次检查项目、主题、关键词和字数。
2. 点击页面下方的生成按钮。
3. 等待写稿完成。
4. 不要因为等待时间长而重复点击。

页面明确写着“生成内容不会自动保存或发布”。生成结束后，右侧才会出现可编辑草稿。

### 7.5 人工编辑草稿

至少检查以下内容：

- 标题是否准确；
- 摘要是否与正文一致；
- 品牌名、产品名是否正确；
- 正文有没有虚构数字、案例、奖项或来源；
- 是否直接回答主题问题；
- 小标题、列表、FAQ 是否适合目标字数；
- 标签是否正确；
- 语气是否符合品牌。

标题、摘要、正文和标签都可以直接编辑。

### 7.6 重新评分并保存

1. 编辑后点击“重新评分”。
2. 查看 GEO Score 和 AI 可引用度。
3. 重点处理 P0 阻断项。
4. 点击“保存到内容库”。

低于 75 分是优化建议，不一定单独阻止发布；P0 风险项会在发布前硬阻断。分数高也不等于内容已经被外部 AI 引用。

## 8. 手动流程二：批量生成草稿

在“AI 内容创作”顶部点击“批量生成草稿”。

1. 先在主页面选好品牌、关键词、长度、内容类型和模板。
2. 打开批量生成窗口。
3. 每行填写一个主题。
4. 一次最多 20 个不重复主题。
5. 点击批量生成。

系统会按顺序生成，单篇失败不会卡住后续主题。成功的文章会直接保存到内容库。批量生成后仍应逐篇人工检查，不要直接全部标记就绪。

## 9. 手动流程三：管理内容库

打开“内容库”。

### 9.1 稿件状态

| 状态 | 含义 |
| --- | --- |
| 草稿 | 仍在编辑、校对或优化 |
| 就绪 | 已完成内部检查，可以进入发布确认 |
| 发布中 | 已进入发布任务流程 |
| 已发布 | 发布流程已经完成 |

### 9.2 常用操作

- 按品牌或状态筛选文章。
- 点击标题或“继续编辑”打开编辑器。
- 点击“GEO 优化”进入优化页。
- 草稿审核完成后点击“标记就绪”。
- 就绪稿件可以点击“进入发布”。
- 如果发现问题，可以把就绪稿退回草稿。

只有就绪稿件会出现在发布中心的稿件选择框里。

### 9.3 Excel 导入

1. 点击“Excel 导入”。
2. 先选择品牌项目。
3. 下载标准 Excel 模板。
4. 按模板填写文章。
5. 选择文件并导入。

不要随意修改模板列名。导入后仍需在内容库检查文章状态和内容。

## 10. 手动流程四：执行 GEO 优化

打开“GEO 优化”，或从内容库点击某篇文章的“GEO 优化”。

### 10.1 生成优化预览

1. 在顶部选择文章。
2. 查看左侧原稿。
3. 查看中间的优化前分数和建议。
4. 点击“AI GEO 优化”。
5. 等待右侧出现优化稿。

优化约束是：保持原意、不编造数据、不堆砌关键词。优化稿只是预览，不会自动覆盖原文。

### 10.2 比较优化前后

重点比较：

- 品牌实体是否更明确；
- 关键词是否自然覆盖；
- 内容结构是否更容易提取；
- FAQ 是否真正解决决策问题；
- 引用和证据是否可追溯；
- 是否新增未经证实的主张；
- P0 阻断项是否清除。

不要只看总分。分数上升但事实发生变化时，不能直接采用。

### 10.3 保存优化稿

确认优化稿正确后，点击“确认覆盖并保存”。保存后可以点击“进入编辑器审核”做最后人工修改。

如果不满意，可以重新优化；每次真实模型调用都可能产生费用。

## 11. 手动流程五：准备素材

### 11.1 在素材管理中上传

打开“素材管理”，点击“上传素材”。

1. 选择图片或视频，可一次选择多个。
2. 单个文件时可以填写自定义文件名。
3. 点击“确认上传”。
4. 上传后使用“预览”检查文件。

删除素材前应确认没有待发布任务仍需使用它。

### 11.2 在发布中心直接准备素材

发布中心也可以：

- 选择并上传图片；
- 智能推荐已有图片；
- 生成文章封面；
- 上传共享视频。

图片要求以页面提示为准；当前发布控制台接受 JPG/JPEG/PNG，保守上限 5MB。视频入口接受 MP4/MOV/MKV/WEBM，保守上限 150MB。

“自动配图”会优先匹配素材库，没有合适图片时使用本地中性封面兜底。只有明确点击“生成封面”且配置了外部 IMAGE 模型时，才可能产生生图费用；结果未知时先检查素材库和成本账单，不要直接重试。

## 12. 手动流程六：登录媒体账号

仅 `authorized_real` 构建并且发布运行时就绪时需要。

打开“媒体账号”：

1. 点击“添加媒体账号”。
2. 选择平台。
3. 填写易识别的账号备注名，例如“知乎品牌主号”。
4. 点击“打开登录流程”。
5. 查看桌面和任务栏，切换到新打开的浏览器、二维码或终端。
6. 由账号持有人完成扫码、验证码、滑块或平台确认。
7. 登录成功后点击完成。
8. 对账号点击“检测登录”，确认状态为“已连接”。

“刷新本地状态”不访问平台；“检测登录”才会显式打开浏览器检查。

### 12.1 微博账号的额外准备

`1.3.1 authorized_real` 已随 EXE 携带固定版本的微博开放平台官方 CLI，不需要另行全局安装 Node.js 或 `@weibo-ai/weibo-cli`。首次添加微博账号前仍须由账号持有人完成平台侧条件：

1. 在微博开放平台完成开发者认证；
2. 领取可用体验服务或开通正式服务；
3. 在“媒体账号”找到微博，点击“添加账号”；
4. 软件打开官方浏览器 OAuth，由本人确认授权；
5. 回到软件检查账号身份和 `doctor` 状态。

官方 CLI 随包不等于账号已授权，也不等于已有发布额度。开发者认证、服务有效期、Credits、写入权限和平台频率限制仍由微博开放平台决定。软件不会读取微博密码，也不会绕过验证码或 OAuth。

退出/解绑只删除本机保存的凭据，不代表平台其他设备已经退出。账号受限、需要本人验证或会话失效时，系统会冻结相关自动发布，不会自动换号。

## 13. 手动流程七：创建发布任务

打开“发布中心”。

### 13.1 选择稿件

1. 在“就绪稿件”中选择一篇或多篇文章。
2. 一次最多选择 20 篇。
3. 如果没有文章，回到内容库把草稿标记为就绪。

### 13.2 选择渠道

点击需要的渠道卡片。系统会为每个“稿件 × 渠道”建立独立任务，所以：

```text
任务数量 = 稿件数 × 渠道数
```

例如 3 篇文章选择 2 个平台，会创建最多 6 个任务。

灰色或显示不可用的渠道不要绕过。常见原因包括构建未授权、运行时未就绪、平台只支持视频或账号能力缺失。

### 13.3 检查平台短版

选择渠道后，页面会生成各平台实际发送的标题和正文副本。

逐个平台检查：

- 原稿字数和实发字数；
- 平台硬上限与软件安全线；
- 标题长度；
- 平台离线预检；
- AI 可引用性分；
- P0 发布阻断项；
- 平台适配原因。

你可以直接编辑平台标题和正文。编辑后等待预检重新完成。

“恢复自动短版”会恢复系统生成的版本；“载入原稿编辑”会把原稿放入当前平台副本。平台副本的修改不会回写内容库原文。

如果只是长度、结构或格式问题，可以点击页面顶部“一键修复并重检”。它不会补造证据、案例或数据。

### 13.4 绑定发布账号

真实发布时，每个平台必须手动选择一个已连接账号。确认账号备注名，避免把品牌内容发到错误账号。

任务创建后账号会被冻结。之后新增账号、换号或重新登录，不会自动修改已经确认的任务。

### 13.5 准备图片和视频

- 图文平台缺图时，选择图片、开启自动配图或生成封面。
- 视频平台必须选择视频。
- 同一共享素材会按本次所选渠道保存到任务。
- 发布前必须实际预览素材，确认画面、版权和品牌信息。

### 13.6 即时发布与定时发布

- 即时：任务创建后，可以立即连续执行。
- 定时 Demo：可以到点自动走演示状态链，不访问平台。
- 定时真实任务：到点只转为“排队中”，仍需人工确认后才访问平台。

真实发布不会在无人值守状态下自动发送。

## 14. 手动流程八：确认并执行发布

### 14.1 先处理所有阻塞项

发布控制台顶部会显示稿件数、渠道数、账号覆盖和阻塞项。主按钮不可用时，点击阻塞提示，按页面定位处理。

常见阻塞包括：

- 没有选择就绪稿件；
- 没有选择渠道；
- 平台短版还在预检；
- 标题或正文超限；
- P0 可引用性门禁未通过；
- 缺少账号；
- 缺少图片或视频；
- 发布时间未填写；
- 真实发布运行时未就绪。

### 14.2 创建任务或立即发布

点击顶部主按钮后，认真阅读确认窗口。确认内容包括：

- 实际发送的文章；
- 所选平台；
- 账号；
- 素材；
- 任务数量；
- 是否立即真实发布。

真实模式会要求强确认。确认后系统按顺序执行，单项异常不会拦住其他任务。

### 14.3 已建任务如何执行

在下方“发布任务”区域：

- Demo 排队任务：点击“执行演示”。
- 单个真实任务：点击“确认真实发布”。
- 多个待发任务：勾选“批次”，再点击“连续发布 N 项”。

不要在任务显示“发布中”时重复点击或打开第二个执行窗口。

## 15. 手动流程九：看懂发布状态

| 状态 | 含义 | 你应该做什么 |
| --- | --- | --- |
| 排队中 | 任务已建立，尚未执行 | 核对正文、账号和素材后确认执行 |
| 发布中 | 正在调用平台 | 等待，不要重试或核验 |
| 发布成功 | 已取得足够成功证据 | 打开平台链接并人工抽查 |
| 发布失败 | 已明确失败或确认未发布 | 修复原因后再重新排队 |
| 待人工确认 | 需要验证，或结果不能确定 | 按下一步提示处理，禁止盲目重发 |
| 计划中 | 等待计划时间 | 真实任务到点后仍需人工确认 |

“发布成功”不一定代表匿名公开访问已验证，也不代表搜索引擎或 AI 已经发现内容。

## 16. 手动流程十：人工核验平台结果

任务出现“核验平台结果”时：

1. 点击按钮。
2. 确认核验的是正确平台和正确账号。
3. 打开目标作品或平台内容管理页。
4. 按精确标题和发布时间检查：作品列表、审核中、草稿箱。
5. 选择“后台确认已发布”或“后台确认未发布”。
6. 填写具体核验说明。
7. 已发布时，按要求填写正确的 HTTPS 公开作品链接。
8. 勾选“我已在正确平台、正确账号下人工核验”。
9. 提交结论。

如果要确认“未发布”，还必须：

- 关闭相关发布或登录窗口；
- 确认旧执行进程已经结束；
- 至少等待 5 分钟；
- 检查作品、审核中和草稿箱；
- 再勾选对应确认项。

人工核验只更新本机任务状态，不会再次点击发布。

## 17. 结果未知时必须怎么做

结果未知表示请求可能已经发给模型或平台，但软件没有拿到可以安全落库的最终结果。

### 模型结果未知

1. 不要立即重新生成。
2. 打开“成本账单”。
3. 核对对应时间、项目、操作和模型。
4. 再到供应商账单核对是否扣费。
5. 检查内容库是否已经生成文章。
6. 确认确实没有结果后，再由人建立新请求。

### 平台结果未知

1. 不要重复点击发布。
2. 打开平台创作者后台。
3. 检查作品、审核中和草稿箱。
4. 使用“核验平台结果”登记事实。
5. 只有确认未发布并完成安全检查后，才能重新排队。

这是防止重复扣费和重复发文的最重要规则。

## 18. 手动流程十一：AI 可见度分析

打开“AI 可见度”。它用于分析外部 AI 回答中是否提及、推荐或引用品牌，不会因为文章已经发布就自动产生有效样本。

### 18.1 最简单的方法：手工导入回答

1. 选择品牌项目。
2. 填写一个明确的监测问题。
3. 按需补充品牌别名和竞品。
4. 把外部 AI 的完整回答粘贴到回答框。
5. 多条回答用单独一行 `---` 分隔。
6. 可填写回答来源和模型标识；它们只是溯源标签。
7. 按需勾选“保存到本机分析历史”。
8. 点击“开始本地分析”。

手工导入不会调用外部模型。

### 18.2 受控 API 采样

如果已经配置 EVAL 模型，可以在页面的真实采样区：

1. 核对模型、服务地址和采样次数。
2. 阅读数据发送说明。
3. 明确勾选外发确认。
4. 开始顺序采样。
5. 查看每次回答、Token、费用和失败分母。

采样结果是当前 API 渠道、当前模型和当前问题的结果，不等于消费者 App/Web 的真实推荐情况。

### 18.3 如何比较优化前后

比较时固定：

- 同一个品牌项目；
- 同一组问题；
- 同一个模型和入口；
- 同样的样本数；
- 同样的地区和时间口径；
- 同一个算法版本。

不要拿不同问题、不同模型或不同样本数直接计算提升率。

## 19. 手动流程十二：官网技术审计

AI 可见度页包含“先确认官网能被公开读取”。

1. 选择已经填写官网的品牌项目。
2. 核对本次检查网址。
3. 勾选外部 GET 范围确认。
4. 点击“检查官网”。
5. 查看页面可访问性、robots、Sitemap、结构化数据和 `llms.txt`。
6. 按 P0、P1、P2 建议整改。
7. 使用最近站点审计记录做复查。

站点审计会真实访问公开网址，但不会调用 AI 模型。结果只说明本次技术条件，不证明已索引、已检索或已引用。`llms.txt` 是建议项，不是 AI 收录保证。

## 20. 手动流程十三：项目诊断

在 AI 可见度页点击“建立客户诊断基线”。系统会读取当前项目资料、内容分数和最近的可见度结果，在本机生成准备度诊断。

完成优化和发布后，使用同一项目点击“重新诊断并留档”。比较前后时要确认诊断版本和输入口径一致。

诊断分是本机确定性准备度，不是模型厂商或搜索平台的官方排名。

## 21. 查看成本账单

打开“成本账单”，可以按以下条件筛选：

- 项目；
- 7 天、30 天、90 天或全部；
- 操作类型；
- 成本状态。

操作类型包括文章生成、GEO 调优、独立 AI 评估、平台适配、AI 可见度采样、AI 生图和模型连接测试。

成本状态含义：

- 已核算：有用量和价格快照；
- 未配置单价：有用量，但没有可靠价格；
- 用量未知：供应商没有返回可核对 Token；
- 用量不完整：只能拿到部分信息。

“未知”不是 0，“未配置单价”也不是免费。最终金额以供应商账单为准。需要交接时可以导出当前筛选范围的 CSV。

### 21.1 设置模型单价

1. 点击账单顶部的“单价设置”。
2. 优先从已检测到的模型列表点击“设置”；也可以点击“新增单价”。
3. 核对服务商标识和模型标识。两者必须与模型调用回执一致。
4. 填写“输入单价”和“输出单价”，单位都是“每百万 Token”。
5. 选择币种，例如 `CNY` 或 `USD`。不同币种会继续分别汇总。
6. 在“价格来源备注”填写供应商价格页和核对日期。
7. 如需处理已经存在的“未配置单价”凭证，开启“补算历史未定价记录”。
8. 阅读确认提示后保存，再返回账单查看费用覆盖率。

保存新价格后，后续模型调用会把当时单价冻结在调用凭证里。修改或删除价格目录不会改写已经核算的历史凭证。历史补算也只处理仍为“未配置单价”的记录，不会重算已经核算的客户账单。

如果供应商只返回总 Token，没有分别返回输入和输出 Token，而输入、输出单价又不同，该条记录仍会显示“用量不完整”，不能用猜测比例强行核算。

## 22. 一键 GEO 怎么用

当你已经手动跑通上述流程，可以进入“一键 GEO”。它会把写稿、优化、预检和发布串行起来。

最简单的操作顺序：

1. 选择品牌项目。
2. 写清本轮优化方向。
3. 每行填写一个文章主题，最多 20 篇。
4. 选择内容类型、目标字数、目标平台和关键词。
5. 先选择“优化并准备”。
6. 选择渠道。
7. 核对右侧文章数、模型调用次数和任务上限。
8. 点击“核对并启动一键 GEO”。
9. 查看写稿、优化、平台预检和发布四阶段轨道。
10. 整轮结束后处理“需处理”条目。

培训时可以选“演示全流程”；只有全部账号和发布条件确认后，才选“真实串行发布”。

暂停时点击“在检查点暂停”。它会等待当前外部调用返回，不会粗暴中断。关闭 App 后状态仍在，但不会在 Windows 后台继续；重新打开 App 后，到“最近运行”打开原 RUN 并继续。

一键 GEO 的字段、三种模式和恢复规则详见 [一键 GEO 使用手册](./一键GEO使用手册.md)。

## 23. 新用户推荐练习

不要第一次就批量真实发布。按以下练习顺序：

### 练习 1：只写一篇

1. 建一个测试品牌项目。
2. 配置写稿模型。
3. 建立蓝图并生成一篇 600 字文章。
4. 人工编辑、评分并保存。

### 练习 2：优化一篇

1. 从内容库打开这篇文章。
2. 进入 GEO 优化。
3. 比较原稿和优化稿。
4. 确认没有新增虚假事实后再覆盖保存。

### 练习 3：Demo 发布

1. 把文章标记为就绪。
2. 进入发布中心。
3. 选择 Demo 渠道和素材。
4. 检查平台短版。
5. 建任务并执行演示。

### 练习 4：一键 GEO 准备模式

1. 选择同一品牌。
2. 填 2 个主题。
3. 选择“优化并准备”。
4. 完成后检查两篇文章和错误轨道。

以上四个练习都能独立完成后，再安排小批量真实发布。

## 24. 常见问题速查

| 问题 | 处理方法 |
| --- | --- |
| 看不到发布中心 | 检查是否是 `safe` 构建，或发布运行时是否被禁用 |
| 内容创作提示没有项目 | 先到品牌项目新建并保存 |
| 生成按钮不可用 | 检查项目、主题、关键词和写稿模型配置 |
| 生成很久没有结果 | 不要重复点击；先等原请求并检查成本账单 |
| 文章不在发布中心 | 到内容库把状态标记为“就绪” |
| 平台按钮灰色 | 当前构建、运行时、渠道能力或素材类型不支持 |
| 没有可选账号 | 到媒体账号添加、登录并检测状态 |
| 短版预检不过 | 按提示缩短标题/正文、补证据或修复 P0 问题 |
| 缺少图片 | 上传图片、智能推荐或生成封面 |
| 缺少视频 | 上传符合要求的视频，文章本身不能替代视频 |
| 发布一直处理中 | 等待；不要重试或人工收口仍在执行的任务 |
| 显示待人工确认 | 完成验证，或到平台后台核验实际结果 |
| 账号重新登录后旧任务不能执行 | 旧任务绑定了旧凭据；重新选择账号并建立新任务 |
| AI 可见度没有品牌提及 | 先检查原始回答、品牌别名和问题，不要只看总分 |
| 费用显示未知 | 供应商未返回完整 usage；到供应商账单核对 |

## 25. 日常标准操作流程

每天或每轮工作建议这样做：

1. 备份工作区。
2. 检查品牌项目是否有变更。
3. 检查模型配置和预算。
4. 建立发布前 AI 可见度基线。
5. 手动生成或一键生成内容。
6. 人工审稿并处理 P0 问题。
7. 做 GEO 优化并保存确认稿。
8. 标记文章就绪。
9. 检查媒体账号和素材。
10. 在发布中心编辑平台短版并完成预检。
11. 小批量发布。
12. 对未知结果先核验，绝不盲目重发。
13. 核对成本账单。
14. 按固定问题和模型进行发布后复测。
15. 保存 RUN ID、文章 ID、JOB ID 和复测结果用于复盘。

## 26. 必须记住的安全规则

1. 生成内容不会自动等于真实事实，必须人工审稿。
2. GEO 分数不等于外部 AI 排名。
3. 预检通过不等于平台审核通过。
4. 发布成功不等于搜索收录或 AI 引用。
5. 模型或平台结果未知时，不自动重试。
6. 真实发布前必须核对账号、正文和素材。
7. 不绕过扫码、验证码、实名或风控。
8. 不把 API Key、Cookie 或本机数据目录发给无关人员。
9. 账号重登或换号后，应重新建立授权任务。
10. 大批量前先用 1–3 篇小样验证质量、费用和平台状态。
