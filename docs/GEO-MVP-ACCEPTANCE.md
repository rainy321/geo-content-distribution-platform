## 必须由项目所有者参与的外部步骤

以下事项不能通过本地 Mock 代替，也不应由自动化擅自执行：

1. 已完成知乎账号人工登录、本地 Cookie 校验与一篇授权测试稿真实发布；后续如 Cookie 失效，需要项目所有者重新登录。
2. 已完成今日头条账号人工登录、Cookie 校验及一次修复后的授权真实发布；平台“已发布”页和公开链接均已核验。后续再次真实发布仍需项目所有者明确授权；系统不会自动重试或自动删除草稿。
3. 真实链路的最终成功依据是平台公开文章链接，而不是自动化脚本是否完成点击；本次知乎链接为 `https://zhuanlan.zhihu.com/p/2078070222595035345`，今日头条链接为 `https://www.toutiao.com/item/7680497457658135090/`。
4. 搜狐号统一真实发布适配器、人工登录、Cookie 复核和授权 dry-run 已完成，但当前账号因“未实名暂无法发布文章”不具备发文资格。是否完成搜狐实名认证只能由项目所有者决定并亲自操作；在此之前系统会停止为 `need_action`，不会继续填写或尝试发布。
5. 当前 API 没有用户认证且 CORS 默认开放，仅适合本地或受控内网；公网部署前需要在反向代理或平台层增加访问控制、TLS，并确认数据库与 Cookie 持久化。
6. 当前 `origin` 指向项目所有者的私有仓库 `rainy321/geo-content-distribution-platform`，`upstream` 保留 OmniPost 的 `rehatRobot/omnipost`，后续提交只推送到 `origin`。
7. Python wheel 与 sdist 已在本机构建、审计并完成隔离安装烟雾；当前机器没有 Docker，因此 Dockerfile、Compose 安全默认值和源码等价部署链路虽已静态/运行验证，容器镜像仍未在本机实际构建。
