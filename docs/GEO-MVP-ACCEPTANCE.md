```powershell

$env:SEED_DEMO_DATA="true"
uv run --extra web python sau_backend.py
```

```powershell

npm run dev
```

访问 `http://127.0.0.1:5173` 后可依次验证：

1. Dashboard 首屏非空，最近发布明确标注 `DEMO / 演示`。
2. “品牌项目”显示“XX科技（示例数据）”。
3. “内容库”显示 6 篇带“示例数据”标签的文章。
4. “AI 内容创作”可在配置模型后生成文章；未配置时返回明确的配置错误。
5. “GEO 优化”可评分并调用 AI 优化。
6. “发布中心”可多选平台、即时或定时创建任务；Demo 任务不访问真实平台。
7. “媒体账号”首次加载只读本地状态，不自动访问平台。

## 必须由项目所有者参与的外部步骤

以下事项不能通过本地 Mock 代替，也不应由自动化擅自执行：

1. 已完成知乎账号人工登录、本地 Cookie 校验与一篇授权测试稿真实发布；后续如 Cookie 失效，需要项目所有者重新登录。
2. 真实链路的最终成功依据是公开文章 API/链接，而不是自动化脚本是否完成点击；本次验收链接为 `https://zhuanlan.zhihu.com/p/2078070222595035345`。
3. 当前 API 没有用户认证且 CORS 默认开放，仅适合本地或受控内网；公网部署前需要在反向代理或平台层增加访问控制、TLS，并确认数据库与 Cookie 持久化。
4. 当前 `origin` 仍指向 OmniPost 上游 `rehatRobot/omnipost`。必须先确认自己的 GitHub 仓库或 fork，再配置目标 remote；不能直接向上游地址推送本次二开。
5. 当前机器没有 Docker，且离线环境缺 wheel 构建工具；Docker 镜像和 wheel 构建尚未在本机执行，源码运行、后端测试和前端生产构建已通过。
