# GEO 1.3.1 一键 GEO 使用手册

> 适用对象：品牌运营、内容运营、发布人员和内部验收人员  
> 适用功能：Windows 桌面 App 中的“一键 GEO”工作台  
> 适用版本：`1.3.1` Windows 桌面版  
> 更新日期：2026-09-17

本文件专门说明“一键 GEO”。如果需要从启动软件、建品牌、手动写稿、手动优化、素材、发布、核验到 AI 可见度复测的完整教程，请先阅读 [GEO 1.3.1 完整使用手册](./GEO完整使用手册.md)。

## 1. 这份手册解决什么问题

这是一份面向实际使用者的操作手册。它告诉你如何准备品牌资料、配置 AI、建立一轮任务、查看运行进度、暂停和恢复，以及遇到错误时应该怎么处理。

“一键 GEO”会把以下步骤串成一条可恢复流程：

```text
品牌项目与优化方向
  → 逐篇写稿
  → GEO 优化
  → 平台副本与离线预检
  → 仅准备、演示执行或真实串行发布
  → 保存每篇文章和每个发布任务的结果
```

它减少重复操作，但不代表文章一定被搜索引擎收录、被 AI 抓取或引用，也不保证平台审核通过。真实效果仍要通过固定问题、固定模型和同口径复测验证。

## 2. 使用前先确认版本和权限

### 2.1 当前交付状态

使用前必须检查随包 manifest 中的版本和 `publishing_profile`。只有 `1.3.1 authorized_real` 包含本手册所述的一键 GEO、可编辑模型单价目录和随包微博官方 CLI；不能因为文件名相似就认为旧 EXE 已包含这些能力。

### 2.2 两种桌面构建

| 构建类型 | 可以做什么 | 不可以做什么 |
| --- | --- | --- |
| `safe` | 建品牌项目、写稿、优化、预检、查看内容和结果 | 不能登录媒体账号，也不能真实发布 |
| `authorized_real` | 在运行时检查通过后，可登录账号并执行受控真实发布 | 仍不会绕过扫码、验证码、实名、平台审核或风控 |

第一次交给新同事使用时，建议先用“优化并准备”，确认内容和流程都正确后，再使用“演示全流程”。只有账号、渠道、授权和内容都确认无误时，才使用“真实串行发布”。

## 3. 开始前的准备清单

启动一键 GEO 前，至少完成以下事项：

- 已登录桌面 App。
- 已建立一个真实的品牌项目。
- 品牌名称、产品名称、官网、描述、关键词和竞品已经核对。
- “系统设置”中的内容生成 AI 已配置并可用。
- 已了解模型调用价格和数据发送范围。
- 如果要真实发布，当前必须是 `authorized_real` 构建。
- 如果要真实发布，Google Chrome 和本机发布运行时必须通过检查。
- 如果要真实发布，目标平台账号必须显示“已连接”。
- 账号持有人能够处理扫码、验证码、滑块、实名或平台风控。
- 已完成工作区备份。

一键 GEO 每篇文章至少会发生一次写稿调用和一次优化调用。页面会显示最低模型调用次数，实际 Token 和费用以供应商账单及 App 的“成本账单”为准。

## 4. 第一次使用：推荐流程

### 第一步：建立品牌项目

1. 打开左侧“品牌项目”。
2. 点击新增项目。
3. 填写品牌名称、产品名称、官网、行业和品牌描述。
4. 添加品牌关键词和竞品。
5. 保存项目。

建议使用稳定、完整的品牌名称。不要把临时活动口号当作品牌主名，也不要把尚未确认的营销数据写进项目事实。

### 第二步：配置内容 AI

1. 打开“系统设置”。
2. 进入统一 AI 引擎配置。
3. 核对服务地址、模型 ID 和 API Key。
4. 保存配置，并先执行连接测试。
5. 确认写稿和优化所需的模型角色处于可用状态。

连接测试通过只代表接口可访问，不代表长文生成一定成功。正式批量运行前，建议先在“AI 内容创作”中生成一篇测试文章，核对语言、事实边界和成本。

### 第三步：准备媒体账号（仅真实发布需要）

1. 打开“媒体账号”。
2. 选择目标平台，点击“添加 / 登录”。
3. 由账号持有人完成扫码、验证码或平台确认。
4. 点击“检测登录”。
5. 确认账号状态为“已连接”。

账号重新登录、解绑或换号后，凭据版本会变化。已经建立的旧运行不会自动改用新凭据；返回一键 GEO 页面后，应刷新页面并重新选择账号，再建立新一轮运行。

## 5. 创建一轮一键 GEO

打开左侧“一键 GEO”。页面分为“品牌与内容清单”“执行模式与渠道”“确认范围”三个部分。

### 5.1 选择品牌与运行名称

1. 在“品牌项目”中选择本轮使用的项目。
2. 填写“运行名称”，例如“9 月采购决策内容覆盖”。

运行名称可以不填，系统会自动使用“品牌名 + GEO 自动化”。启动后会冻结品牌项目快照；之后修改项目，不会静默改变正在运行的批次。

### 5.2 填写 GEO 优化方向

“本轮 GEO 优化方向”应该说明这批内容要回答谁的问题、重点覆盖什么决策场景，以及必须遵守的事实边界。

推荐写法：

> 面向中小企业采购负责人，重点回答部署成本、适用范围、上线周期和风险边界；只使用项目中已经确认的事实，不编造客户案例或效果数字。

不要只写“提高 GEO”“写得专业一点”这类无法核验的空泛目标。

### 5.3 填写文章主题

- 每行填写一个主题。
- 空行会被忽略。
- 完全相同的主题会自动去重。
- 一轮最多 20 个不重复主题。

建议第一轮先放 1–3 个主题。确认生成质量、费用和平台副本后，再增加批量数量。

### 5.4 设置内容参数

| 字段 | 怎么填 |
| --- | --- |
| 内容类型 | 可选行业科普、品牌介绍、产品介绍、解决方案、对比文章、FAQ 或新闻稿 |
| 目标字数 | 200–3000 字；短渠道不要直接选择过长文章 |
| 写作目标平台 | 可不选；不选时按分发渠道和通用规则生成 |
| 品牌关键词 | 至少选择一个；默认会带入项目已有关键词，也可以补充本轮关键词 |

## 6. 选择执行模式

### 6.1 优化并准备

系统执行写稿、GEO 优化和平台预检，但不创建发布任务，也不访问媒体平台。

适合：

- 第一次试用；
- 只需要批量准备稿件；
- 需要人工审稿后再发布；
- 当前是 `safe` 构建；
- 账号或平台运行时尚未就绪。

这是新用户最推荐的模式。

### 6.2 演示全流程

系统会创建并执行演示发布任务，但不会访问真实媒体平台。

适合：

- 培训新同事；
- 检查发布状态变化；
- 验证失败后继续下一篇的流程；
- 在正式发布前演练操作。

如果按钮不可选，表示当前环境没有可用的 Demo 渠道。

### 6.3 真实串行发布

系统会为每篇文章和每个渠道创建独立任务，并按顺序访问平台执行。

只有同时满足以下条件时才能选择：

- 使用 `authorized_real` 构建；
- 真实发布运行时检查通过；
- 目标渠道显示可用；
- 每个渠道都绑定了明确的已连接账号；
- 账号凭据版本仍与页面当前读取到的版本一致；
- 操作员有权发布这些内容。

一键 GEO 当前只展示适合文章自动化的渠道。要求视频素材的渠道不会进入本流程；视频发布应在发布中心单独处理。

部分图文渠道需要图片。系统会尝试准备安全的默认封面；如果素材准备或平台门禁不通过，该条目会被暂存为“需要处理”，不会绕过要求继续发送。

## 7. 选择渠道和账号

1. 勾选至少一个渠道。
2. 查看渠道下方的状态说明：
   - “生成平台副本并执行门禁”：当前是仅准备模式；
   - “演示可用”：可执行 Demo；
   - “真实发布运行时就绪”：当前环境允许建立真实任务；
   - “当前不可用”：不要尝试绕过。
3. 如果选择真实发布，为每个渠道选择一个明确账号。

同一个平台有多个账号时，必须确认账号名称，不要依赖默认顺序。启动后文章、渠道、账号和凭据版本都会被冻结。

## 8. 核对并启动

右侧“执行范围”会显示：

- 品牌；
- 文章数量；
- 最低模型调用次数；
- 渠道数量；
- 发布任务上限；
- 当前运行模式。

发布任务上限等于“文章数量 × 渠道数量”。例如 3 篇文章、2 个渠道，最多会建立 6 个发布任务。

点击“核对并启动一键 GEO”后，再核对确认弹窗：

1. 品牌是否正确；
2. 主题数量是否正确；
3. 渠道是否正确；
4. 是否选中了真实发布；
5. 最大任务数量是否在预期内。

真实模式必须点击“确认真实执行”。确认后不要再到其他页面修改运行中的文章或账号。

## 9. 如何看运行进度

每篇文章都有四个阶段：

1. 写稿；
2. GEO 优化；
3. 平台预检；
4. 发布。

符号含义：

| 符号 | 含义 |
| --- | --- |
| `✓` | 该阶段已经完成 |
| `●` | 当前正在执行 |
| `○` | 尚未执行 |
| `!` | 此阶段需要人工处理或失败 |
| `—` | 当前模式不适用，例如“仅准备”不执行发布 |

运行顶部会显示“完成、需处理、待执行”的数量。单篇文章失败后，系统会保存错误证据并继续下一篇，不会把整轮卡住。

运行过程中，文章会锁定，避免用户编辑和自动化同时覆盖正文。运行结束或条目暂存后，可以点击 `ARTICLE` 打开文章；已经建立发布任务时，可以点击对应 `JOB` 前往发布中心查看。

## 10. 暂停、关闭和恢复

### 安全暂停

点击“在检查点暂停”后，系统不会强行中断已经发出的模型请求或平台提交，而是等待当前外部调用返回，再停在安全检查点。

因此，点击暂停后按钮不一定立刻变成“已暂停”。不要关闭浏览器窗口、结束 Chrome 或强制结束 App 来代替安全暂停。

### 继续运行

运行暂停后，点击“继续安全步骤”或“继续执行”。系统会读取已保存的文章、检查点和发布任务，不会从第一篇重新开始。

### App 意外关闭

运行状态保存在本机数据库中。重新打开 App 后：

1. 进入“一键 GEO”；
2. 在“最近运行”中打开原来的 RUN；
3. 点击“刷新”；
4. 查看是否存在“需要处理”或结果未知；
5. 只有界面允许时再点击“继续执行”。

一键 GEO 由当前 App 页面驱动，不是 Windows 后台服务。关闭 App 后不会在后台继续下一篇。若关闭时外部调用已经发出但结果尚未保存，系统会保守地标记为结果未知，不会自动再次调用。

## 11. 运行结束后怎么处理

### 全部完成

1. 打开每篇文章，抽查标题、事实、品牌名和引用边界。
2. 打开“成本账单”，核对模型、Token 和费用。
3. 真实发布时，打开发布中心检查每个渠道的任务状态和公开链接。
4. 记录本轮 RUN ID，方便复盘。

### 完成，部分需处理

1. 找到带 `!` 的文章。
2. 阅读“已暂存，主流程继续”下面的错误说明。
3. 点击 `ARTICLE` 查看文章，或点击 `JOB` 前往发布中心。
4. 完成人工修复或平台核验。
5. 如需重新生成或重新发布，建立新一轮任务，不要反复点击旧的未知结果任务。

## 12. 常见问题和正确处理方式

| 页面提示或现象 | 原因 | 正确处理 |
| --- | --- | --- |
| “先选择品牌项目” | 没有项目 | 到品牌项目新建或选择项目 |
| “填写本轮 GEO 优化方向” | 方向为空 | 写清目标人群、问题和事实边界 |
| “至少填写一个文章主题” | 主题为空 | 每行填写一个主题 |
| “一次最多 20 篇” | 主题过多 | 拆成多轮，先运行优先级最高的一批 |
| “至少选择一个品牌关键词” | 项目或本轮没有关键词 | 添加标准品牌名、产品名或核心业务词 |
| 渠道显示不可用 | 当前模式、构建或运行时不支持 | 更换模式，或让维护人员检查构建和运行时 |
| 要求绑定明确账号 | 真实模式未选账号 | 回到媒体账号确认连接，再重新选择 |
| “账号缺少凭证版本” | 页面账号信息过旧 | 刷新/重新进入页面，再选择账号 |
| 账号凭据已变化 | 账号重登、解绑或换号 | 不继续旧授权；刷新账号后建立新一轮 |
| 模型请求结果未知 | 请求可能已经到达供应商，但结果未安全写回 | 先核对成本账单和供应商账单，不要立即重复运行同一主题 |
| 平台结果未知或待核验 | 平台可能已接收内容，但软件没有确定证据 | 进入发布中心和平台创作者后台检查，禁止盲目重发 |
| 平台预检阻断 | 内容、长度、证据、素材或风险项未通过 | 打开文章修复，重新建立一轮；不要绕过 P0 门禁 |
| 一篇失败后下一篇继续 | 这是设计行为 | 等整轮完成后统一处理“需处理”条目 |
| 无法切换到另一运行 | 当前运行仍在本页面执行 | 先安全暂停或等待当前运行结束 |

## 13. 费用、数据和安全

- 一键 GEO 会调用已配置的内容模型，可能产生费用。
- 模型调用结果和费用回执以“成本账单”和供应商账单共同核对。
- 媒体账号、Cookie、文章和项目数据保存在本机工作区，不要把整个数据目录上传到公共网盘。
- 不要向不受信任的人提供 API Key、媒体账号扫码、验证码或登录窗口控制权。
- 不要用结束进程的方式处理正常运行中的平台提交。
- 真实发布前必须确认内容权利、品牌授权、账号授权和平台规则。

## 14. 推荐的日常 SOP

1. 备份工作区。
2. 核对品牌项目事实。
3. 检查 AI 配置和预算。
4. 第一轮先用“优化并准备”。
5. 人工抽查文章和预检结果。
6. 用“演示全流程”培训或验证状态链。
7. 检查媒体账号状态。
8. 小批量选择“真实串行发布”。
9. 保持一键 GEO 页面和必要的登录窗口打开。
10. 运行结束后核对成本账单、发布中心和平台后台。
11. 对结果未知的任务先核验，不自动重发。
12. 使用固定问题和采样协议做发布后 GEO 复测。

## 15. 交接给新同事时的验收清单

让新同事独立完成以下动作，才算真正会使用：

- 能建立并核对品牌项目；
- 能解释优化方向与文章主题的区别；
- 能配置并测试内容 AI；
- 能说明三种执行模式的安全边界；
- 能建立一轮 1–3 篇的“优化并准备”任务；
- 能看懂四阶段运行轨道；
- 能执行安全暂停和恢复；
- 能找到文章、发布任务和成本账单；
- 遇到结果未知时不会盲目重试；
- 能说明“一键 GEO 完成”不等于 AI 已经收录或引用。

更完整的桌面首次启动、口令、备份和媒体账号说明见 [首次使用](./首次使用.md)。技术架构、状态机和开发边界见 [GEO AI 开发与系统详细说明](./GEO_AI开发与系统详细说明.md)。
